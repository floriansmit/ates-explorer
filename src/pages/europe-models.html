European hydrogeological model inventory

Reviewed 26 October 2026. This is an integration-oriented inventory of verified model families and supporting datasets, not an exhaustive catalogue of every European model. A viewer, a groundwater-body map, a geological framework and a numerical hydrogeological model are different products. Only Netherlands and Denmark are connected in ATES Explorer; Other works worldwide with user input. API availability, current model versions, coverage, resolution and licences must be checked before adding each provider.

Priority is an engineering assessment: first investigate DOV/Flanders and Latvia LAMO; pursue Estonia with EGT in parallel. Then select specific regional models in Germany, Sweden, Finland, France and the UK. EGDI is a discovery/hosting route, not one homogeneous European aquifer model.
